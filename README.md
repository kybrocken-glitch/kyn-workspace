# Kyn Workspace

Shared workspace for the Kija x Kyn work: Ky's story artifacts, Kiel's pitch tools, decks, and shared docs.

## What goes where

- `stories/` - Ky's tap-through story artifacts. Start with `barrys_story_v2_si_first.html`, the current Studio Intelligence first version.
- `pitch-tools/` - Kiel's pitch builders for Studio Intelligence, the Kyn app, and Nutrichef.
- `decks/` - pitch decks and snapshots meant to be shared or presented.
- `assets/` - logos, photos, brand files, and other source material.
- `docs/` - shared working docs and the snapshot production rules.

## Working rules

- Keep client-facing artifacts in the folders above, not in email threads.
- Name files plainly: client or studio, what it is, version if needed.
- When you replace a version, keep the old one or note what changed in the commit message.
- Internal Kija-only items (founder terms, commission, private planning) do not belong in this repo.

- Kiel: pitch tool used on the booked call to close.
